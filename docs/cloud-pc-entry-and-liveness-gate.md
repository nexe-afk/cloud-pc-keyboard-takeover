## 0. 先说清哪些没定案

- 本轮**没有拿到键鼠正向判决**：远端媒体流全程冻结（像素零变化），且会话时长到期。
- 键鼠通的结论沿用前几轮（另有 commit 与文档记录）；本轮新增的是**状态机**与**帧存活门控**。

## 1. 弹窗状态机（本轮实测）

进入云电脑页会遇到的界面不止一种，**先识别再点**，否则点了无效按钮会误判成「连接坏了」。

| 状态 | DOM 判据 | 动作 |
|---|---|---|
| A 实例面板 | 可见按钮 `进入桌面` 与 `结束订单` 同屏（`modalMain___I9d1U`） | 点 `进入桌面` |
| B 连接失败 | 弹窗正文含 `连接失败，请重新连接`，按钮 `结束订单` / `重新连接` | 点 `重新连接`（约 4 秒恢复，不必刷新） |
| C 落地页 / 未开始 | 帧静止但非黑（mean≈213），DOM 出现可见 `点击开始游戏` | 点 `点击开始游戏` |
| D 时长不足 | 温馨提示 `您的可用时长不足 N 分钟`，按钮 `关闭` / `稍后充值` / `立即充值` | 先关掉，可能挡交互 |

### 识别代码（宽松匹配）

按可见文本**包含**关键字扫，比 `innerText === 关键字` 稳（按钮常包嵌套 `span`，用 `children.length===0` 过滤会漏）：

```js
const KW = ["重新连接", "点击开始游戏", "进入桌面", "连接失败", "正在重连"];
const hits = [...document.querySelectorAll("button,div,span,a")].filter(
  e => e.offsetParent !== null && KW.some(k => (e.innerText || "").includes(k))
);
```

## 2. 桌面就绪判据（三条，缺一不可）

1. `window.airLinks.pc` 为真；
2. `airLinks.pc.videoElement.readyState === 4` 且 `videoWidth > 0`（本轮实测 1920x1080）；
3. **帧存活**：连续两次采样画面有变化（见第 3 节）。

只满足 1+2 **不等于**进了桌面。本轮实测到：`pc` 为真、`rs=4`、`currentTime` 持续前进、`datachannelDelay=58ms`，但画面**逐字节不变** —— 传输层活着、渲染管线停帧。

## 3. 帧存活门控（必须，否则探针全是假阴性）

静止画面下任何像素差分探针都读到 0，会被误读成「键鼠没通」。**做输入探针前先测底噪**：

```js
const cap = () => { g.drawImage(v, 0, 0, 128, 72); return g.getImageData(0, 0, 128, 72).data.slice(); };
const b1 = cap();
await new Promise(r => setTimeout(r, 1200));
const b2 = cap();
// 若 diff(b1, b2).px === 0 → 本次测量作废，禁止下结论
```

- 底噪有变化 → 探针有效，继续；
- 底噪为 0 → **停手**，先解决停帧（点 `进入桌面` 重连 / `重新连接` / 重新下单）。

## 4. 画面形态量化（黑屏 / 静止 / 有内容）

用 128x72 缩略图算统计量，比肉眼看截图可编程：`mean` 亮度、`std` 标准差、分行均值看上下结构。

本轮实测 `mean 213.7 / std 59.7 / rows [224,229,227,175]` → 亮底、有结构，**不是黑屏**，是落地/加载画面。黑屏应满足 `mean < 8`。

## 5. 只有拿到活流才做输入探针

```js
const noise = diff(base1, base2);        // 门控
if (noise.px > 0) {
  kbd.tap("win");    // diff 大变化 → 键盘通
  kbd.tap("escape"); // diff 回落到接近底噪 → 复原
  mouse.click(2);    // diff 变化 → 鼠标通
}
```

## 6. 本轮踩到的坑

- `pc.videoElement` 全页只有一个（已核实 `querySelectorAll("video")` 长度为 1），别把停帧归因于「采错元素」；
- 停帧时 `currentTime` **仍在前进**，不能拿它当存活证据；
- 单次 `page_eval` 别超 10 秒：阻塞式长调用会打断站点信令心跳，把会话搞成「连接失败」；
- 页面刷新 / 重连后注入层失效：注入时闭包捕获了 `pc`，实例被换掉而引用不变 → **调用不报错、事件丢进黑洞**。

## 7. 恢复手法

- 断连 → 点 `重新连接`（本轮实测约 4 秒恢复）；
- 停帧 → 点 `进入桌面` 重连（本轮试过，帧仍只有 2 个取值，未恢复，属远端侧问题）；
- 时长耗尽 → 只能 `结束订单` 后重新下单。
